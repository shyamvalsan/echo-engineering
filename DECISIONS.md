# Decisions

Every choice the spec left open and every deviation from it, one line each with the reason.
Format: `- [task N] <choice> — <reason>`. Append only (`cat >> DECISIONS.md`); never rewrite.

- [task 1] Package layout: `echo/` and `stages/` are regular packages at the repo root, built by hatchling and installed editable by uv; pytest also gets `pythonpath = ["."]` — so `uv run python -m stages.s1_bird` and `uv run pytest` both work from the root.
- [task 1] Wedge membership (`in_wedge`) uses polar angle and distance about the source; delay-related quantities use bistatic range rho — the wedge is a placement region, rho is the delay coordinate.
- [task 1] `Scene.r_max = None` means "outermost post edge (or r_min if no posts)"; scene.json always writes a number — viewer needs a numeric r_max.
- [task 1] `Scene.depth_m` = max - min post bistatic range — "total range depth" of the structure.
- [task 1] Clap = Gaussian noise x (0.25 ms raised-cosine attack, exponential decay, cosine tail), shaped zero-phase by a log-Gaussian spectrum around its peak (sigma 0.45-0.6 octave) times a 300-600 Hz high-pass, stored in an 8 ms buffer (128 samples), residual DC removed with a Hann-shaped correction, peak-normalized — meets 2-5 ms, 1-4 kHz, peak ~2.5 kHz, zero DC.
- [task 1] Clap family: 7 defined variants (durations 2-5 ms, peaks 2.0-3.0 kHz), `clap_family(n=5)` default uses the first 5; noise seeded per variant with `default_rng([seed, k])` — deterministic, and adding variants does not change earlier ones.
- [task 1] `band_limit` is an FFT mask with raised-cosine edges (width max(50 Hz, 25 % of edge)), zero-padded to avoid wrap — exactly zero phase, no filter-order choices, works on batched arrays.
- [task 1] Air absorption implemented from ISO 9613-1 eqs. (3)-(5) with the Annex B saturation-pressure formula; tested against ISO 9613-2 Table 2 values (20 C/70 % and 10 C/70 %), which are the published ISO 9613-1 numbers I could cite exactly.
- [task 1] Bird whistle glides exponentially (constant octaves per second) from 3.5 to 2.0 kHz — a pitch glide sounds linear in log frequency; pure tone with 5 ms raised-cosine fades.
- [task 1] Note targets: pure tones, 5 ms raised-cosine fade in and out on every note (10 ms dip between notes) — keeps repeated notes (E6 E6, G6 G6) separable at 45-100 ms note lengths. Motif uses the spec's rounded Hz; melody uses equal temperament A4 = 440 Hz.
- [task 5] Viewer: Scene and Wave share one canvas (field video registered under the plan view by `field.extent_m`, toggle "Field") — the spec's Wave panel is "the pressure field animated over the scene"; two copies of the scene would halve its size at 1440x900.
- [task 5] Viewer: wavesurfer.js drives only the footer timeline strip (peaks + `setTime` from the shared clock, its clicks call `clock.seek`); Echo and Groove are hand-written canvas — they must share a zoomable time window and draw the echo up to the cursor, which wavesurfer's own media/zoom model fights. Audio plays through Web Audio (`playbackRate` = speed) so picture time comes from `AudioContext.currentTime`.
- [task 5] Viewer: uPlot for History only; spectrograms are canvas images from `spectrograms.json` (one shared colour LUT).
- [task 5] Viewer: field.webm is fetched whole and played from a blob URL — `python -m http.server` ignores Range requests and Chrome cannot seek a video served without them.
- [task 5] Viewer: falls back to `viewer/fixtures/runs` when `../runs/index.json` is missing or empty, and says so in the header; the one 404 for `../runs/index.json` in the console is that probe.
- [task 1] Torch switched to the PyTorch CPU index (`[tool.uv.sources]`, torch 2.15.0+cpu) — the default PyPI CUDA build pulled ~3 GB of nvidia wheels at ~0.5 MB/s (over an hour); brief allows CPU torch. `torch.cuda.is_available()` is False. GPU for Tier 1 stays with Task 3 (k-wave's CUDA binary does not need CUDA torch).
- [task 1] uv selected CPython 3.11.15 for the venv (requires-python >= 3.11) — left as is; spec allows 3.11+.
- [task 1] Clap "spectral peak" is measured as the energy-weighted geometric-mean frequency (log centroid) — a 2-5 ms noise burst has only a handful of spectral degrees of freedom, so argmax of its spectrum is random; each variant keeps the best of 16 (32 after review fix) seeded noise draws (closest log centroid to its design peak, most energy in 1-4 kHz, least below 300 Hz), so family properties hold for any seed.
- [task 1] Clap duration is the -40 dB extent of the burst (envelope 0.25 ms attack, exp decay tau = dur/2.5, cosine tail) — it lands at 0.85-0.95 x the nominal 2-5 ms.
- [task 1] k-wave-python downloads its C++ binaries (OMP + CUDA, GitHub release v1.4.1) into `.venv/.../kwave/bin/linux/` on first `import kwave`; on this network that took many minutes, so the first import can appear to hang.
- [task 1] `tests/test_imports.py::test_import_kwave` skips (with reason) until both k-wave binaries have their `*_metadata.json` — importing kwave mid-download blocks and starts a second, competing download into the same file. At commit time the CUDA binary (298 MB) was still downloading in a detached process; the OMP binary was complete.
- [task 1] `in_wedge(..., rho_min=None)`: optional bistatic lower bound (`bistatic_range >= rho_min`) replacing polar `r_min` when given; default unchanged — posts realized on the rho = 3.0 ellipse sit at polar r = 2.9925 m on axis and must count as inside.
- [task 1, review fix] Shortest clap variant raised from 2.0 to 2.3 ms nominal so every variant's -40 dB extent is within the spec's 2-5 ms (measured 2.1-4.8 ms over seeds 0-3); 0.3 ms raised-cosine onset ramp added so clips start at 0 (cropped pre-ringing had left a step of ~0.5 at sample 0).
- [task 1, review fix] Clap selection now 32 draws, cost = 3*|log2(centroid/peak)| + (1 - in-band fraction) + 20*(<300 Hz fraction) + 1 if that fraction > 5e-4 — the onset ramp shifted the trade-off; with this, seeds 0-9 x 7 variants meet every bound except seed 4 variant 4 (centroid 7 % low).
- [task 2] Tier 0 3D amplitude: point source + infinitely tall vertical post, axial-wavenumber decomposition of the point source and stationary phase at kz = 0 give H = d sqrt(2/(pi k r1 r2 (r1+r2))) e^{i pi/4} conj(T) e^{-ik(r1+r2)} (2D form function T, 3D spreading); reduces to the convex-mirror geometric-optics result d sqrt(a)/(2 r^1.5) at large ka — derivation in the echo/tier0.py docstring. Overestimates far, low-frequency echoes of real (finite-height) posts.
- [task 2] Tier 0 time convention: physics in e^{-iwt} (H^(1), e^{+ikr}); returned spectra are conj(physics) so they use numpy's rfft convention (delay = e^{-iw tau}), t = 0 at emission — one convention for every signal in the repo.
- [task 2] Tier 0 2D: exact H0 on both legs and the direct path via H0 = sqrt(2/(pi x)) e^{i(x-pi/4)} Q(x), Q from a dense log-x table below x = 12 and Hankel's asymptotic series above (error < 1e-8); plane-wave incidence at the post (vs the exact Graf-series line-source solution: <= 0.25 dB at 3 m, <= 0.1 dB at 10 m, 500-4000 Hz, 1 and 8 cm posts).
- [task 2] Tier 0 form function evaluated exactly (full partial-wave series, cos(n delta) at each post's own bistatic angle — no small-angle expansion, so a listener moved 1 m stays exact); partial-wave tables cached per radius rounded to 0.01 mm (jittered radii share tables at that resolution).
- [task 2] Tier 0 fast path: for kr >= 12 the per-(post, frequency) exponent -ikL - alpha (L-d) + conj(log Q1 + log Q2) is a sum of outer products (one matmul + one complex exp); the exact-table path is used for the few low bins with kr < 12. Both paths are cross-checked by the profile/post consistency test.
- [task 2] profile_echo: on-axis transfer evaluated at geometric rho nodes (ratio 1.01), SVD-factored (cutoff 1e-9) and interpolated linearly in rho; the sum over bins is an exact chirp-z transform (bins are 58.3 us apart, not on the sample grid). Agrees with post_echo of the equivalent on-axis posts to 2-4e-5 relative RMS. The plan is cached per (geometry, c, mode, a_ref, n_rho, n_fft, band).
- [task 2] Tier 0 FFT length = next power of two >= max(n_out, last echo + clap) + 1024 samples (tail margin for the 2D t^-1/2 wake); band=(f_lo, f_hi) applies exactly the raised-cosine mask of echo.clap.band_limit in the frequency domain.
- [task 2 review] Tier 0 form function: one master partial-wave table on a ka grid (step 0.004, grown on demand) replaces per-radius tables cached by lru_cache; radii sit on a 0.5 mm grid with linear blending between neighbouring grid radii (catalog radii exact) — a +-1 mm jitter of 3000 posts now costs ~1.7x the catalog case instead of rebuilding hundreds of scipy tables; error vs exact per-radius <= 0.014 dB / 0.002 rad (500-6000 Hz).
- [task 2 review] Finite post height (3d loudness only, optional `post_height`, `ear_height=1.5`): the stationary-phase axial integral is truncated to z in [0, h] paraxially, giving F = [E(s_top) - E(s_bot)]/(1+i) (Fresnel integrals) per post and frequency; free space, no ground reflection (out of scope) — with the ear near the post foot the lower half of the Fresnel zone is missing, which a rigid ground's image would partly restore, so the finite-height level is conservative.
- [task 4] Profile starts at bistatic r0 = 3.06 m; loss band = clap band (family-mean power within -20 dB of peak: 898-4965 Hz) ∩ design band = 898-4000 Hz.
- [task 4] Solve loss: auraloss MR-STFT (FFT 64/128/256/512, hop 1/4) + log-mel L1 (256-pt, 40 mels in band), each signal RMS-normalized inside the echo window (scale-invariant: absolute level is set by physics and density). Profile scale set afterwards by `target_fill`.
- [task 4] Reference/preferred radius a_ref = 1 cm (spec: small posts): at equal fill, 1 cm posts give 4x the posts (better sampling of the 4.9 cm-period profile) and ~2x the echo of 2 cm posts; larger radii only where an arc is too crowded. Radius weight = band-mean |T_a|/|T_aref|.
- [task 4] Realization: continuous inverse-CDF (midpoint quantile) ranges, then 100 Adam steps polishing post ranges to match the profile's Tier 0 transfer in band (weighted by clap power) — realization fidelity, not a target loss; golden-ratio angles, gap hard, no-shadow within 0.5 m of range.
- [task 4] Stage-1 default target_fill = 0.01 (moderate; the Tier 1 loop should tune it).
- [task 4] Pitch judge: pyin frame 256 / hop 32, frame times shifted by -frame/8 (calibrated on the clean glide); metric = worst interior frame (12 ms edges excluded), pyin best guess used on every frame; mean over clap family vs 3 %. Note: pyin reads a clean 2500 Hz tone as ~2528 Hz (+1.1 %, its 10-cent grid).
- [task 4] Aggregation: every metric averaged over the clap family; boolean note-sequence metrics averaged as fractions with threshold 1.0 (all claps must be correct); per-clap values reported.
- [task 3] Tier 1 engine is our own 2D staggered-grid FDTD (8th-order stencils in free air, leapfrog, numba-compiled, float32, 8 CPU cores, split-field PML of 24 cells), logged as solver "fdtd". It is not k-Wave. The k-Wave benchmark was skipped for time. k-Wave's import-time download hook was still fetching the 298 MB CUDA binary, and the GPU route (GTX 1650, WSL2) was not worth the risk. We also needed direct control of the rigid sub-cell inclusions, many sensors and field snapshots. A k-space pseudo-spectral variant was tried first and dropped: rigid posts need a stiffness and density contrast that the non-local spectral operator cannot hold stably, and the stable versions were off by ±8 dB on 4 and 8 cm posts.
- [task 3] Dispersion is corrected exactly along the grid axes by reading the spectra at w' with 2 sin(w'dt/2)/dt = c k_fd(k). The source-listener line and the wedge axis are grid axes. The residual phase-velocity error at 9 points per wavelength (ppw) and f_max is < 2e-5 off-axis (8th-order stencil, theory), well under 0.5 %.
- [task 3] Rigid posts are area-fraction rasterized. Faces use 1/rho = (1-phi)/(1+phi), nodes use K = 1/(1-phi) capped at 3. Nodes and faces with phi >= 0.9 are solid: K = 0 and closed faces, and faces touching solid nodes are closed too, which removed a pressure-release sink and trapped modes. Within r + 5 dx of a post the stencil blends to 2nd order (exact Yee rigid wall, no wide stencil across solids). dt shrinks by sqrt(max local K*B) for sub-cell posts.
- [task 3] Grid: ppw 9 at f_max (stage 1: dx = 0.3/32 = 9.4 mm). Chosen from the measured cylinder table: ppw 5 failed 1 cm (-1.45 dB), 4 cm and 8 cm. At ppw 9 every radius is within 1 dB at the tested offsets. Each single-post run takes seconds.
- [task 3] Sub-cell calibration: area factor 0.912 at r/dx = 1.06 (1 cm at the stage-1 grid, 2 cm at the stage-3 grid), 1.0 at r/dx >= 2.125, linear in between (tier1.AREA_CAL). Uncalibrated, 1 cm read +0.6 to +1.2 dB flat across the band at 4 offsets. Calibrated, it reads -0.46 to +0.55 dB at 4 offsets. At r/dx = 0.53 (1 cm at the stage-3 grid) the error depends on offset (-0.3 to -2 dB), so it is not validated.
- [task 3] Tier 1 air absorption uses the extra path c t - |SL|, the same as Tier 0 (global constraints say c t; the difference is 0.3 m of path, negligible).
- [task 3] The empty-scene check compares the listener record with the analytic 2D free field (one fitted complex gain) and applies the clap family to the residual. The physical 2D wake of a line source is part of the direct arrival, so it is excluded by construction.
- [task 13a] BUILD.md generated block lists runs with status "final" or "tier0_only" (no "final" run exists yet); intermediate runs are excluded.
- [task 13a] Rigid-ground estimate = image method on top of Tier 0 finite-height 3d: direct term (post doubled to [-h,h], ear at h+z) + image-source cross term (post moved onto the ellipse rho + d/2, d = sqrt(L^2+4z^2) - L, ear at the doubled post's middle); reference stays the free-field direct clap. Grass is not modelled.
- [task 13a] Build-physics tables score degraded echoes (jitter, slices, height, ground, temperature) with the stage's own judges (echo.metrics.stage_values) on the Tier 0 3d echo — judges only, nothing is optimized; a code-evaluated "Readout" in the block turns them into the rules BUILD.md's prose points at, so no simulated number is typed by hand.
- [task 13a] Stake-out build order = 0.5 m bistatic-range bands, farthest first, boustrophedon by bearing; second-tape control points B+/B- at mid-structure x, |y| = ceil(max|y|+1 m).
- [task 13a] 1:10 template tiles on 600x400 mm panels (common laser bed), each hole owned by the panel holding its centre, edge-crossing holes also cut on the neighbour (HOLES_SPLIT); a full-size (1:1) deck template on 2440x1220 sheets is produced too. DXF = hand-written ASCII R12, mm.
- [task 4, review fix] Note judge is told only the stage's nominal note length (and searches pitch in the fixed 400-4200 Hz band); boundaries = envelope dips with >= 3 dB prominence plus pitch-change peaks >= 70 cents, both >= note/2 apart; notes shorter than 0.4 x note length dropped. Correct on target*clap for all 5 clap variants (motif, melody 100/60 ms).
- [task 4, review fix] Range polish uses the non-aliased FFT length (choose_n_fft over the largest delay) with an exact, post-chunked gradient; skipped (and logged) above 20,000 posts or 2.5e7 posts x in-band bins. StageConfig.max_posts (default 40,000) caps the post count by scaling the profile.
- [task 4, review fix] Arc angles: golden-ratio sequence plus seeded Gaussian jitter (0.15 of the wedge width) per candidate, so there is no lateral lattice; "nearer" for the shadow rule is measured in bistatic range (the placement order).
- [task 4, review fix] Manifest git_dirty counts tracked modifications under echo/ and stages/; untracked files there (other agents' work in progress) are listed separately in git_untracked_paths.
- [task 13a fix] Placement jitter in the build tables: 3 seeds per sigma (mean and range); "radial" = along grad rho, "tangential" = along the ellipse; judged against a judge floor (same judges on clap * target at the design delay); the readout's radial budget is the largest sigma up to which every sigma passes (a later pass never extends it); missing judges print "not judged", never FAIL.
- [task 13a fix] Low-pitch build variant (bird glide 1.75 -> 1.0 kHz, stage-1 config, Tier 0 only, 1 thread) written under build/variants/, not runs/; tolerance cached in its tolerance.json. Result: in-target-band correlation stays ~1 but out-of-band (clap top octave) scatter grows, so lower pitch alone is not a tolerance lever with a broadband clap.
- [task 13a fix] 1:10 option A ground plane = top face of the upper guide plate; pins = H/10 + 56 mm plate stack (option B: + 15 mm hole depth). 2 cm class stock = smooth Ø20 bar (B500 rebar is ~22-23 mm over ribs).
- [task 3 fix] Engine fd8-3: each derivative point uses the widest staggered stencil (2nd/4th/6th/8th order) that reads no solid node (velocity updates) and no closed face (divergence). This replaces the old 2nd-order zone of r + 5 dx around every post, whose Yee dispersion was -2 % at 4 kHz and covered about 31-59 % of ray paths in the dense stage-1 field. Partial (sub-cell) cells keep the 8th-order stencil. Only cells next to a solid point drop order, and for 1 cm posts at r/dx 1.17 that is a few cells.
- [task 3 fix] Grid is now 10 points per wavelength at f_max (spec minimum for finite differences). It was 9, which was an unlogged deviation. Stage 1: dx = 0.3/35 = 8.57 mm.
- [task 3 fix] 1 cm calibration re-fitted for fd8-3 at ppw 10. Fitting offsets (post centre minus the nearest node): (0, 0), (3.5, 5.3) and (5.3, 2.1) mm. Uncalibrated errors were +0.55, +1.20 and +0.79 dB, all flat across 500-4000 Hz. The fitted area factor is 0.908 at r/dx = 1.167, and 1.0 at r/dx >= 2.333 (2 cm needs no calibration: +0.34, +0.46, +0.62 dB). Validated on 10 held-out random offsets plus forward and 90-degree bistatic angles (runs/validation/metrics.json).
- [task 3 fix] dt uses max(probe, actual scene) of sqrt(max K*B). The probe keeps dt stable across designs so the empty-scene cache keeps hitting. The empty-scene cache key includes a hash of echo/tier1.py, so stale entries are impossible. Old entries were deleted.
- [task 3 fix] Benchmarks: stage-1 box (17.5 x 12.5 m, 3000 x 1 cm posts, f_max 4 kHz).

  - ppw 10 (fd8-3): 2.91 M cells, 19,920 steps (CFL 0.25); 23 ms/step while the stage-1 agent shared the CPU, so about 470 s loaded; about 3 min expected on an idle machine.
  - The empty-scene run is the same size again, once per grid and c (cached).
- [task 6] Correction loop (spec step 3): reference = target convolved with each clap, band-limited (the physically perfect echo); 10 ms windows over [t_echo0, t_echo0 + note + clap); gain sqrt(E_ref/E_t1) after scaling the reference to the echo's total energy (shape only, total profile mass kept so the fill is unchanged); windows 25 dB below the reference peak keep gain 1; gains clipped to [0.5, 2] per round; mapped to bins at 2 rho/c + clap energy centroid with linear interpolation; same realization seed every round — level-only arithmetic, no judge.
- [task 6] "Score" for keep-best/stop: min relative margin over the gating metrics ((thr-v)/thr for <=, (v-thr)/thr for >=). Loop stops at the first round that does not improve it, or after correction_rounds Tier 1 runs (5) counting the uncorrected design as round 0.
- [task 6] Optional density sweep (StageConfig.fill_candidates) picks the fill by the Tier 1 spectrogram loss (echo.inverse.window_loss), never by a judge; off unless configured.
- [task 6] Robustness listener positions: "sideways" = +1 m in y (across the wedge axis), "back" = -1 m in x (away from the posts); evaluation window shifted by the geometric delay change of the on-axis mid-structure point. Jitter: UNIFORM per axis in [-5, +5] mm for x and y, radius uniform [-1, +1] mm, seed = stage seed + 1000. c cases: window starts at 2 r0 / c; the pitch shift expected from c alone, (c/343 - 1)*100 %, is reported next to the measured median shift.
- [task 6] fragile = (exactly one clap variant passes on its own) or (exactly one of {nominal, 1 m sideways, 1 m back} passes) — the spec's "only works for one clap or one listener position", literally; a design passing nowhere is failing, not fragile.
- [task 6] Verification: verified only if runs/validation/metrics.json has passed:true, every check in it with a pass flag passes, its solver.engine equals echo.tier1.ENGINE_VERSION (recorded as manifest.solver.engine), and every radius used is validated at a grid there with the same f_max and ppw (else StageConfig.validated_radii, logged as config-sourced).
- [task 6] Every Tier 1 run of a stage uses the same 3 sensors (nominal, side, back) so the empty-scene cache is shared; the final design is rerun once with field recording (deterministic, ir identical) rather than recording the field in every correction round.
- [task 6] Field video: zero pressure = viewer background #0e1620 exactly (LUT entry 128); symmetric limit = 99.97th percentile of |p| outside the direct pulse's first passage (|r - c t| > 1.2 m); asinh compression k = 2; time gain = 0.6 of the fitted post-peak decay of that level, capped at t^1. Favours dynamic range (the viewer has a gain control).
- [task 6] Finite-height 3D level (2 m posts, ear 1.5 m, Tier 0 post_height, tier-gap corrected) is an extra informational headline key (echo_level_db_re_direct_finite_height); manifest field block keeps exactly the contract keys (colour parameters go to metrics.tier1_correction.field_colour).
- [task 9] espeak-ng obtained user-space: `apt-get download` of Ubuntu focal espeak-ng 1.50 (+ espeak-ng-data, libespeak-ng1, libpcaudio0, libsonic0) and `dpkg -x` into .cache/espeak/root, run with LD_LIBRARY_PATH and --path; no sudo. Raw 22.05 kHz WAVs are committed in artifacts/speech/raw/ and preferred by the loader, so stage 4 does not need espeak-ng.
- [task 9] Speech targets: voice en-us, default pitch; durations set by espeak speed, not by stretching or cutting phonemes: ah 240 wpm (central 150 ms of the steady vowel kept), ma 250, ba 230, om 250, hello 195 wpm; crop to voiced extent (-40 dB) +5 ms, 5 ms fades, band-limit 500-4000 Hz, peak 1. "om" given as phonemes [[oUm]] ("ohm"): espeak's letter rules read the text "om" as /Am/.
- [task 9] ESTOI on 200-400 ms utterances: pystoi needs >= 30 frames (384 ms) after silent-frame removal and returns 1e-5 otherwise. Options: (1) tile the utterance, (2) concatenate the three syllables for one joint score, (3) pad with silence (useless: silent frames are removed). Chosen (1): echo aligned to target, both given the same 5 ms end fades and tiled back-to-back to >= 1 s; it scores each echo against its own target only. Sensitivity: 0.6 / 1 / 2 s tiling changes ESTOI by <= 0.03.
- [task 9] Closed-set judge: DTW (Euclidean, normalised by n+m) over 40-band log-mel (500-4000 Hz, 25 ms / 10 ms, dB re own max, -60 dB floor) with per-band time mean removed, so a fixed convolutive colouring (the clap) does not decide the nearest target.
- [task 9] Formant judge: resample to 10 kHz, pre-emphasis 0.97, 25 ms Hamming every 5 ms, LPC order 10, roots 250 Hz-4.95 kHz with bandwidth < 400 Hz; F1, F2 = median over frames centred in the middle 60 % of the window within 10 dB of the loudest; per clap value = max(F1 err, F2 err); threshold on the mean over claps.
- [task 9] Recognizer: faster-whisper small (local .cache/whisper-small, int8, 2 threads), language en, beam 5, temperature 0 (no fallback), no previous-text conditioning, no initial prompt, VAD off; input = echo alone, peak-normalised, 0.25 s zeros each side. Hit = "hello" is a whole token of the lowercased, letters-only transcript. .cache/whisper-small/tokenizer.json was truncated (1.08 MB) and was re-fetched (2.2 MB) from Systran/faster-whisper-small.
- [task 13a fix 2] Jitter evidence is reported like-for-like: per-clap residual (jittered - g x nominal) energy split into fixed bands below / in / above the target band (glide endpoints) to 4 kHz, clap-family mean, reconciled with 1 - corr^2; the earlier pooled "out-of-band share" is no longer shown. The fitted G = 0.5 coherence formula is dropped for the parameter-free A = exp(-sigma_phi^2/2).
- [task 13a fix 2] SNR gate = lowest SNR from which every seed passes every judge on nominal echo + in-band white noise, plus 6 dB; gate margins: INCONCLUSIVE band = |threshold - judge floor| on the fail side; site clearance = c (last echo + 10 ms) / 2; caches keyed on params + buildkit.py + compute-function source.
